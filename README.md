# Placement Predictor

A Machine Learning based Placement Predictor built using Flask, Python, HTML, and CSS.

## Features

- Placement prediction using Random Forest
- Placement probability score
- Personalized recommendations
- Modern dashboard UI
- Reset functionality

## Tech Stack

- Python
- Flask
- Pandas
- Scikit-Learn
- HTML
- CSS
